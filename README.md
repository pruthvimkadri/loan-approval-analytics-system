# Loan Approval Analytics System
AI-powered loan approval prediction and analytics dashboard using Flask, Machine Learning, SQLite, and Power BI.
## Project Description
Developed an AI-powered Loan Approval Analytics System using Flask and Machine Learning to predict loan approvals and visualize analytics through interactive dashboards and Power BI reports.
## Features
- Loan approval prediction using Machine Learning
- Flask-based web application
- Login authentication system
- SQLite database integration
- Analytics dashboard with charts
- Prediction history tracking
- Approval/Rejection statistics
- Power BI dashboard visualization
  ## Tech Stack
- Python
- Flask
- Pandas
- Scikit-learn
- SQLite
- HTML/CSS
- Chart.js
- Power BI
